# AgriN Connect v2

AgriN Connect is an enterprise-grade distributed agricultural intelligence platform bridging satellite Earth observation, hyper-local microclimate telemetry, computer vision pathology, and cryptographically verified data exchange for smallholders and cooperatives worldwide.

### Core Capabilities
- **Foliar Pathology & Vision-LLM**: Laplacian blur gate with ViT and Vision-LLM diagnosing leaf diseases and prescribing dual-tier bio-control & targeted chemical treatments.
- **Satellite Remote Sensing (NDVI)**: Sentinel-2 L2A STAC integration tracking 60-day crop vigor with interactive 3D canopy simulation.
- **Agro-Ecological Telemetry**: Batched Open-Meteo forecasts, fungal spore risk heuristics, and ISRIC SoilGrids chemical-physical depth profiling.
- **Cryptographic Mesh**: HMAC-SHA256 signed telemetry protocol for zero-trust cross-border data exchange.
- **Smallholder Workspace**: Localized for India, Brazil, Russia, China, South Africa, and Ethiopia with dynamic hectare/acre conversion.
